# 综合能源业务网络

一个以呼和浩特为调度中心的能源业务网络可视化页面，展示全国重点业务城市、业务分布信息和城市之间的能源连接关系。

## 项目特点

- 深蓝色科技感地图界面
- 省级地图渐变与玻璃质感效果
- 呼和浩特调度中心与业务城市节点
- 业务城市之间的动态能源连线
- 光线按业务城市顺序发射，完成后保留线路
- 自动业务展示与镜头聚焦
- 点击省份或城市查看业务分布详情
- 选中省份高亮、浅色填充和泛光效果
- 地图下方能量脉冲网格动态背景
- 固定在右下角的业务详情弹窗

## 运行方式

项目不需要安装前端依赖，使用 PowerShell 启动本地静态服务器即可：

```powershell
powershell -ExecutionPolicy Bypass -File .\server.ps1 -Port 5180
```

启动后访问：

```text
http://localhost:5180/
```

也可以将端口替换为其他未占用端口。

## 目录说明

```text
energy-network-dashboard/
├─ data/
│  └─ china.geojson       中国省级地图数据
├─ app.js                 地图绘制、路线动画和交互逻辑
├─ index.html             页面结构
├─ styles.css             页面样式与动效
├─ server.ps1             本地静态服务器

```

## 主要交互

- 点击业务省份或城市节点，打开对应的业务分布信息。
- 自动展示期间点击地图会暂停自动计时，连续 1 秒无操作后从当前进度继续。
- 点击关闭按钮或按 `Esc` 可以关闭业务详情弹窗。

## 数据说明

地图轮廓数据位于 `data/china.geojson`，业务城市和业务文案位于 `app.js` 的 `regions` 配置中。
